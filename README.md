# VOGUE — Fashion E-commerce Product Page

A premium modern fashion e-commerce product page developed as part of the Saiket Systems Web Development Internship — Task 2.

## Features
- Premium modern fashion product design
- Responsive layout for desktop, tablet and mobile
- Product image gallery
- Product color and size selection
- Quantity selector
- Add to Bag interaction
- Wishlist toggle
- Size guide modal
- Related products section
- Toast notifications

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Google Fonts
- Unsplash Images

## Project Structure
```text
Task-2-Ecommerce-Product-Page/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    └── images/
```

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.

## Note
This is a frontend demonstration project. Real payments, order processing, and backend functionality are not connected.
